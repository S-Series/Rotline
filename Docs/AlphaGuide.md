# Rotline Alpha 0.1

## 실행

Unity에서는 `Assets/Scenes/MainMenu.unity`를 열고 Play를 누릅니다. Windows 빌드는 `Builds/RotlineAlpha/Rotline.exe`로 실행합니다. 빌드의 Data 폴더와 DLL을 실행 파일과 함께 유지해야 합니다.

메뉴 → 캐릭터/모드 선택 → 전투와 성장 → 결과 → 영구 강화 → 다음 도전으로 이어지는 오프라인 싱글 플레이 알파입니다. 기존 Gameplay를 직접 실행하는 개발용 흐름도 유지합니다. 전체 빌드의 첫 장면은 MainMenu입니다.

메뉴의 기본 모드는 **Gameplay 필드 / 10분 생존**입니다. 그대로 출발하면 Gameplay 씬에 저장한 타일맵과 플레이어 시작 위치를 사용합니다. 씬에서 필드를 수정하고 저장하면 다음 시작에 반영됩니다. 모드 버튼으로 **무작위 방 탐험**을 선택한 경우에만 실행 중 필드를 5개 방으로 교체합니다.

## 캐릭터와 모드

### 메인 메뉴 편집

`MainMenu` 씬의 `Main Menu > Menu Canvas` 아래에 `Home`, `Character Selection`, `Permanent Upgrades`, `Collection`, `Settings` 화면이 저장되어 있습니다. Play 전에도 하이어라키에서 펼쳐 버튼과 텍스트를 편집할 수 있습니다. 비활성 화면은 해당 오브젝트를 활성화해 편집하고, 기본 화면은 `Home`만 활성화해 두면 됩니다.

위치·크기·색상·고정 문구는 각 UI 오브젝트의 Inspector에서, 버튼 동작은 Button의 On Click에서 수정합니다. 캐릭터 설명과 강화 제목은 `Main Menu`의 AlphaMainMenu 컴포넌트에서 수정합니다. 재화·선택 상태·가격·설정 값은 플레이 중 갱신됩니다. 화면 전환은 기존 패널을 켜고 끄며 UI 오브젝트를 재생성하지 않습니다. 도감 항목을 늘리려면 행을 복제하고 해당 컴포넌트의 Item Rows 또는 Attack Rows에 연결합니다.

메뉴용 Canvas, UI Input, Menu Audio도 씬에 배치되어 있습니다. 한글 글꼴은 프로젝트에 포함된 `NanumGothic-Regular.ttf`를 사용하며 라이선스는 `NanumGothic-OFL.txt`에 포함되어 있습니다.

플레이 중 UI는 `Gameplay` 씬의 `Survival Run > Run HUD`와 `Alpha System Pages`에 저장되어 있습니다. 보상·일시정지·결과·상점·설정·장비 화면은 Play 전에 비활성 오브젝트를 켜서 Inspector에서 편집할 수 있습니다. 화면 전환과 값 갱신은 기존 오브젝트를 사용합니다.


- **광전사:** 체력 100, 검 공격, R로 광폭화. 흡혈과 자연 회복 차단이 적용됩니다.
- **유랑 사수:** 체력 70, 원거리 탄환, 이동속도 8. 별도의 R 능력은 없습니다.
- **방 탐험:** 시드에 따라 동쪽 또는 북쪽으로 이어지는 5개 방을 생성합니다. 전투(15킬) → 보물 → 전투(25킬) → 상점 → 최종 보스 순서입니다. 목표 달성 전에는 출구가 잠깁니다. 보물과 상점은 방 중앙의 표시 근처에서 F로 이용합니다.
- **생존:** 기존 필드에서 10분을 버팁니다. 시간이 지날수록 스폰 빈도·체력·피해가 증가합니다.

같은 시드에서는 같은 방 배치가 생성됩니다. 알파는 분기 없는 연결 경로이며, 향후 갈림길·숨겨진 방 등을 추가할 수 있습니다. 방 사이의 이동은 실제 통로를 이용합니다.

## 전투와 성장

적 3종은 추적자, 도약형, 원거리형입니다. 최종 보스는 붉은 원으로 예고한 뒤 방사형 탄막을 발사합니다. 체력이 줄면 탄막이 강화됩니다. 적과 탄막은 재사용하고 수량을 제한합니다.

적 처치 후 경험치를 모아 레벨업하면 3개 중 하나의 능력치 아이템을 선택합니다. 보물에서는 충전 빔·충전 고리·다중 발사·궤도 효과를 얻고 조합할 수 있습니다. 기존 아이템 5개의 아이콘은 모두 빈 상태입니다. 색상 사각형은 임시 적·드롭·상호작용 표식입니다.

오염 위에서는 기본적으로 이동속도가 25% 감소하고 2초마다 피해 2를 받습니다. 광전사의 둔화 저항이 적용됩니다. E로 정화 모드에 전환해 조준한 오염을 자동으로 제거합니다.

일반 공격과 정화는 해당 모드에서 자동 실행됩니다. 좌클릭 유지·해제는 차지 공격에만 사용합니다. 정화는 기존보다 5배 빠르게 진행됩니다. 전투 모드에는 공격 사거리와 조준 방향, 발사 순간의 표시가 나타납니다. 제거한 오염 칸은 기본 5초 동안 재오염되지 않습니다. 설정과 하이어라키 편집 방법은 [오염·정화 안내](Purification.md)를 참고하세요.

적 한 마리당 동전 2를 얻습니다. 상점에서 동전 8로 체력 30을 회복하거나, 동전 12로 공격력 +2 또는 공격속도 +20%를 구매합니다. 각 상품은 방문당 한 번만 구매할 수 있으며 나가면 다음 문이 열립니다. 동전은 한 판에서만 유지됩니다.

## 영구 진행과 저장

판이 끝나면 처치가 있는 경우 `max(1, 처치 수 / 5의 정수부)`만큼 정수를 받고, 승리하면 25를 추가로 받습니다. 처치 없이 바로 포기하면 정수를 받지 않습니다. 도중 메뉴로 돌아가면 실패로 정산합니다. 결과를 여러 번 처리해도 같은 판의 보상을 중복 지급하지 않습니다.

메뉴의 영구 성장은 각각 최대 5단계입니다. 비용은 15에서 시작해 단계당 15씩 증가합니다.

| 강화 | 단계당 효과 |
| --- | --- |
| 생명력 | 최대 체력 +10 |
| 전투 훈련 | 공격력 +1 |
| 흡수 감각 | 수집 반경 +0.3 |

정수, 강화, 발견한 아이템, 원정·승리 기록, 최고 처치·생존 기록, 음량과 화면 설정을 `Application.persistentDataPath/alpha-profile.json`에 저장합니다. 임시 파일을 쓴 뒤 교체하며 `.bak` 백업으로 손상된 주 파일을 복구합니다. 저장 실패는 메뉴에서 표시하고, 결과 정산 실패는 결과 화면에서도 알립니다. 실패한 정산은 메뉴 복귀와 씬 종료 때 다시 시도합니다. 실패한 발견 기록은 같은 실행의 다음 저장에서 다시 시도하며, 성공 전에는 프로필에 확정하지 않습니다. 테스트는 프로젝트 Logs 아래 별도 파일을 사용합니다.

**중간 런 이어하기는 지원하지 않습니다.** 실행 중 종료하면 미정산 런의 보상은 받지 않으며, 이미 저장된 영구 진행은 남습니다.

## 조작

WASD 이동 / 마우스 조준 / 일반 공격·정화 자동 / 좌클릭 유지·해제 차지 / Shift 이동 방향 회피 / Q 전투 / E 정화 / R 고유 능력 / F 상호작용 / ESC 일시정지.

일시정지 메뉴에서 현재 장비·능력치를 확인하거나 음량·조작법을 열 수 있습니다. 결과 화면에서 재시작 또는 메인 메뉴로 돌아갑니다. 새 판은 이전 런의 아이템·적·탄막·경험치를 초기화하고 영구 강화만 적용합니다.

## 주요 파일

- `Assets/Resources/AlphaCatalog.asset`: 캐릭터, 무기, 적, 보스, 보상 설정 참조.
- `Assets/Data/Alpha`: 캐릭터 2종과 적 4종의 능력치.
- `Assets/Data/Runs/SurvivalRun.asset`: 생존 시간과 레벨업·보물 보상.
- `AlphaArena`: 시드 기반 방·통로·문 생성.
- `AlphaRunController`: 방 목표, 상점, 동전, 결과 정산과 메뉴 복귀.
- `AlphaProfileStore`: 버전이 있는 저장 데이터와 백업, 중복 정산 방지.
- `AlphaChecks`: 메뉴부터 탐험 완료, 상점, 저장 복구, 생존 모드·재시작까지 통합 검증.

Unity 메뉴의 `ROTLINE > Alpha > Install Alpha`로 개발용 장면 연결을 다시 구성하고 `Build Windows Alpha`로 실행 파일을 빌드할 수 있습니다.

## 알파 범위

핵심 시스템을 처음부터 끝까지 시험할 수 있는 버전입니다. 캐릭터·적·보스 수와 방 종류는 적고, 미술·애니메이션·음악·이펙트·장기 밸런스는 임시입니다. 입력 재설정, 다중 저장 슬롯, 중간 런 저장, 분기 던전, 컨트롤러 전용 조작, 온라인 기능은 포함하지 않습니다.
