# 오염과 정화

Gameplay 씬에서 바로 Play하거나 메뉴에서 Gameplay 필드 모드로 시작합니다.

- 적 사망 지점에 오염이 생기고 지면을 따라 퍼집니다. 장애물과 필드 밖에는 생기지 않습니다.
- 적 사망 지점 주변과 확산으로 번진 칸은 희미한 상태에서 시작해 기본 1.5초에 걸쳐 짙어집니다. 완전히 오염된 칸만 다음 칸으로 확산합니다. 번지는 도중 정화하면 그 칸의 오염도 증가가 멈춥니다.
- E로 정화 모드, Q로 전투 모드로 전환합니다. 선택한 모드의 일반 행동은 버튼 입력 없이 자동 실행됩니다. 좌클릭을 누르고 놓는 조작은 차지 공격에만 사용합니다.
- 정화 모드에서 오염 칸을 조준하면 자동으로 정화합니다. 기본 정화 강도 1, 오염 저항 0.2이므로 한 칸은 약 0.2초 분량의 정화력이 필요합니다. 3×3에 오염된 칸이 여러 개라면 정화력을 나눠 적용합니다.
- 사거리 원 안의 막히지 않은 목표만 정화할 수 있습니다. 조준 표시가 붉으면 사거리 밖이거나 장애물에 막힌 상태입니다.
- 오염은 정화 진행에 따라 옅어집니다. 다른 곳을 조준하거나 모드를 전환해도 해당 칸의 정화 진행은 유지됩니다.
- 정화가 조금이라도 진행된 오염 칸은 더 이상 주변으로 확산하지 않습니다. 정화를 멈춰도 남은 정화량과 확산 억제 상태가 유지됩니다. 완전히 오염된 다른 칸은 계속 퍼질 수 있습니다.
- 제거한 칸은 기본 5초간 적 사망과 확산에 의한 재오염을 막습니다. 보호 시간은 게임 시간 기준이며 일시정지 중에는 줄지 않습니다.
- 화면 오른쪽 아래에서 오염 칸 수, 누적 정화 칸 수, 현재 목표의 진행률을 확인합니다.
- 오염을 밟으면 이동속도가 기본 25% 줄고 2초 간격으로 피해 2를 받습니다. 정화하거나 벗어나면 둔화가 해제됩니다.

## 하이어라키에서 편집

- `Game System`의 **CorruptionField**: 오염 Tilemap 연결, 사망 시 오염 반경, 확산 간격/양/최대 수, 새 칸이 완전히 오염되기까지의 시간(`Spread Growth Seconds`, 기본 1.5), 칸당 저항(`Resistance Per Cell`, 기본 0.2), 재오염 보호 시간(`Protection Seconds`). 오염 Tilemap에 미리 칠한 오염도 Play 시 유지합니다.
- `Player`의 **PlayerPurificationController**: 필드·카메라·게임 진행 연결, 정화 범위 칸 수(`Purification Radius Cells`), 시야를 가리는 레이어. 기본 범위 1은 조준한 칸을 중심으로 모서리를 포함한 3×3 정사각형입니다. 중앙이 깨끗해도 주변 오염을 정화합니다. 같은 정화력을 범위 안의 오염 칸에 나눠 적용합니다.
- 캐릭터 정의의 **Purification Power / Range / Efficiency**: 초당 정화력·사거리·효율. 효율은 정화력에 `1 + 효율`로 곱해지므로 0.5는 +50%입니다. 아이템의 능력치 효과도 이 값을 통해 반영됩니다.
- `Player`의 **AlphaCorruptionHazard**: 오염 위 둔화율·피해·피해 간격.
- `Purification Display` 하위 **Purification HUD / Status Panel / Status**, **Range Ring**, **Target Ring**, **Purification Beam**: HUD 배치·크기·글꼴·색과 조준 표시의 굵기·재질. 오브젝트는 씬에 저장되며 실행 중 새로 만들지 않습니다. HUD의 수치와 조준 표시 위치만 플레이 중 갱신됩니다.
- `Attack Feedback` 하위 **Attack Range**, **Attack Aim**, **Attack Pulse**: 전투 모드의 사거리 원, 조준선, 공격 순간의 빛. 원은 검의 공격 사거리와 원거리 투사체의 이동 거리를 반영하며, HUD에도 수치가 나타납니다. 선의 색과 굵기는 각 오브젝트의 Line Renderer와 `AttackFeedbackView`에서 조정합니다.

정화는 현재 안전한 이동 공간 확보를 위한 행동입니다. 정화 자체에 경험치나 영구 재화 보상을 지급하지 않습니다. 누적 정화량은 이번 플레이의 통계이며 재시작 시 초기화됩니다.
