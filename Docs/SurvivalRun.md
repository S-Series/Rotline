# 생존 런 시스템

Gameplay 장면을 실행하면 기존 이동·전투·정화 위에 10분 생존 런이 시작됩니다. 아이작의 공격 변형 보상과 뱀파이어 서바이버즈의 경험치 수집·선택 성장 흐름을 조합했습니다.

## 한 판의 흐름

- 적 처치 위치에 파란 경험치 조각이 생깁니다. 가까이 가면 끌려오며 PickupRange가 흡수 반경을 늘립니다. 기본 접촉 반경은 0.65입니다.
- 첫 레벨업에는 경험치 5가 필요하며 이후 필요량은 1.25배 증가합니다. ExperienceGainRate가 실제 획득량에 반영되고 초과 경험치는 보존됩니다.
- 레벨업하면 시간이 멈추고 기존 임시 능력치 아이템 중 서로 다른 3개가 제시됩니다. 하나를 고르면 즉시 적용되고 게임이 재개됩니다. 한 번에 여러 레벨이 오르면 선택창을 차례대로 표시합니다.
- 25킬마다 노란 보물이 떨어집니다. 충전 빔·충전 고리로 공격을 변형하거나, 변형된 공격에 다중 발사·궤도를 조합할 수 있습니다. 공격 변형이 없는 근접 무기에는 다중 발사·궤도 단독 보상이 나오지 않습니다. 공격 효과의 최대 중첩에 도달하면 후보에서 제외됩니다.
- 분홍 드롭은 체력을 10 회복합니다. 기본 확률은 5%이며 행운 1당 0.5%p 증가합니다. 최종 확률은 0~100%로 제한합니다.
- 매 60초마다 다음 단계로 넘어갑니다. 단계마다 기본 대비 스폰 빈도 +35%, 새 적 체력 +25%, 새 적 접촉 피해 +15%가 누적됩니다. 기본 동시 적 제한은 160입니다.
- 10분을 생존하면 성공, 체력이 0이면 실패합니다. 결과 화면에서 새 판을 시작할 수 있습니다. 재시작은 경험치·아이템·드롭·적·공격 변형을 초기화합니다.

## 생존과 기존 능력치 연결

- 적과 플레이어가 서로 통과하는 기존 물리 설정을 유지하면서 실제 콜라이더 간 거리를 검사해 접촉 피해를 줍니다. 피격 후 0.7초 동안 추가 피해를 받지 않습니다.
- 피해 감소는 `피해 × (1 - DamageReduction)`입니다. 최대 체력이 줄면 현재 체력을 제한하고, 늘어났다고 무료 회복하지 않습니다.
- HealthRegen은 초당 회복량입니다. 광폭화 중 자연 회복 차단과 실제 가한 피해에 비례한 흡혈을 연결했습니다. 회복 드롭은 자연 회복 차단과 별개입니다.
- 치명타 확률은 0~1, CriticalDamage는 피해 배율입니다. 배율이 미설정(0)인 기존 캐릭터는 치명타 발생 시 1.5배를 사용합니다. KnockbackPower는 0.15초 동안 적용하는 밀치기 속도입니다.
- 버서커가 비활성일 때 기본 자원 회복량에 ResourceRegen을 더합니다.
- 정화 처리량은 `PurificationPower × (1 + PurificationEfficiency)`입니다. 효율 0은 기존 동작, 0.2는 20% 증가입니다.
- Shift로 이동 방향 회피: 이동속도의 2.5배로 0.18초 이동하며 무적, 재사용 대기시간 1.2초. 이동 방향이 없으면 발동하지 않습니다.

## 조작과 화면

WASD 이동, 마우스 조준, Q/E 전투·정화 모드, R 고유 능력, Shift 회피, ESC 일시정지. 일반 공격과 정화는 선택한 모드에서 자동 실행됩니다. 좌클릭 누름·유지·놓기는 충전 공격에만 사용합니다. 보상 선택과 결과 화면에서는 게임 입력과 시간이 함께 멈춥니다.

체력·경험치·레벨·처치·남은 목표 시간·최근 획득 보상을 HUD에 표시합니다. 아이템 아이콘은 비어 있습니다. 월드 드롭은 구분용 색상 사각형이며 아이템 아이콘을 대체하지 않습니다.

## 데이터 및 확장 지점

`Assets/Data/Runs/SurvivalRun.asset`에서 제한 시간, 단계 길이, 적 수 제한, 드롭과 보상 후보를 수정합니다. 레벨 보상은 ItemDefinition, 보물은 RunReward로 구성하며 능력치 아이템 또는 AttackRecipeModifier 하나를 연결합니다. 공격의 조합 우선순위는 기존 공격 시스템 규칙을 따릅니다.

PlayerHealth는 피격·회복·사망, PlayerExperience는 경험치·레벨, SurvivalRunController는 런 상태와 보상, RunPickupField는 드롭 재사용, SurvivalRunHUD는 표시를 담당합니다. 드롭은 최대 512개를 유지하며 한도 도달 시 경험치는 기존 조각에 합쳐 유실을 막습니다.

이 문서는 Gameplay를 직접 실행하는 개발용 생존 런을 설명합니다. 메뉴에서 시작하는 알파에는 시드 기반 방 생성, 문·상점, 보스 전용 행동, 영구 성장과 저장이 추가되었습니다. `AlphaGuide.md`를 참고하세요. 조준은 마우스로 하며 일반 공격과 정화는 자동 실행됩니다.

`Gameplay` 씬의 `Survival Run > Run HUD`에 상태 HUD, 보상 선택, 일시정지·결과 화면이 저장되어 있습니다. `Alpha System Pages`에는 상점·설정·장비 화면이 저장되어 있습니다. Play 전에 하이어라키에서 비활성 화면을 잠시 활성화해 배치와 문구를 편집할 수 있습니다. 런타임은 저장된 UI의 값과 활성 상태만 갱신합니다.

## 검증

SurvivalRunChecks.RunBatch는 실제 Gameplay에서 접촉 피해, 무적, 처치 드롭, 경험치 배율과 초과분, 중복 없는 보상, 연속 레벨업, 공격 변형, 일시정지, 사망, 재시작, 시간 제한 승리를 검증합니다. 기존 CombatRegressionChecks 및 CombatPlayModeChecks로 전투 호환성을 확인합니다.
